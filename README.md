# 💖 Heart Animation Website

Beautiful animated heart with rotating text declarations and dynamic effects.

## Features ✨

- 🎨 Animated glowing heart with pulsing effects
- 💎 5 rotating text declarations with emojis
- ⭐ Particle effects and orbiting stars
- 🌸 Decorative SVG flowers and stars on sides
- 📱 Fully responsive design (optimized for iPhone 15 Pro Max)
- 🔥 3D text flip animation with backface visibility
- 💫 Multiple glowing effects and shadows

## Text Declarations 💬

1. 💎 "Ты мой самый драгоценный подарок"
2. 🔥 "С тобой я ощущаю настоящую любовь"
3. ⭐ "Ты моя звезда в темной ночи"
4. 👑 "Королева моего сердца и мечтаний"
5. 🌙 "Ты светлее луны и красивее звёзд"

## Technologies 🛠️

- HTML5
- CSS3 (Animations, 3D transforms, Gradients)
- No JavaScript required!

## How to Use

Simply open `index.html` in your web browser.
